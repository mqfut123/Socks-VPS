# Socks-VPS 踩坑

- **TCP RST 与正常 EOF 不同。** v1.3.1 修复双向转发忽略 `io.Copy` 错误的问题；实际错误关闭双方，正常 EOF 保留 `CloseWrite`，避免截断合法响应。记录见 [error](../error/README.md)。
- **多个 A 记录需要共享总期限但保留尝试机会。** 首个地址不能消耗全部 numeric-IP 拨号预算；既有循环分配剩余时间，仍服从解析与拨号总期限，不增加重复地址尝试。
- **Bash 条件调用会抑制 errexit。** 自检失败必须显式传回调用方，不能因后续端口检查成功而打印认证正常。
- **nft 查询失败不等于表不存在。** 复用既有所有权读取，确认 absent 才能报告撤销成功；外部同名对象保持不变。
- **无操作不需要写入前置条件。** 同版本更新和未修改连接设置不能触发依赖安装、停服或配置写入，见 [实现偏好](implementation-preferences.md)。
- **当前生命周期不能从初版基线推断。** 初版包含备份恢复；后续的多配置与永久删除契约以根 README 和实现偏好为准。
- **发布包通过与实机通过分别记录。** 本地 mock、包摘要和公开下载不能证明 Linux systemd、CN 规则计数、真实流量或与 WARP 同机共存，当前缺口见 [todo](../todo.md)。
