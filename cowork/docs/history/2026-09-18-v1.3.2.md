# Socks-VPS v1.3.2 历史交接

历史交接：以下行为、发布与验证范围对应 v1.3.2。现行约束见[根AGENTS](../../../AGENTS.md)，当前状态见[项目待办](../../todo.md)，版本导航见[时间线](../timeline.md)。

更新时间：2026-09-18

v1.3.2 增加按实例保存的 Xray/SOCKS `socks://` 导入链接。安装和新增配置时生成链接，连接结果、`list` 与 `status` 展示已保存链接；公网 IPv4 变化时可用 `socks-vpsctl link [CONFIG]` 主动刷新。

## 公开版本

- Release：[`v1.3.2`](https://github.com/mqfut123/Socks-VPS/releases/tag/v1.3.2)。
- 公开稳定入口：`https://github.com/mqfut123/Socks-VPS/releases/latest/download/install.sh`。
- 发布资产：`install.sh`、Linux amd64/arm64 压缩包及各自 SHA-256 文件，共五项。
- 分享链接使用标准 Base64 编码的 `用户名:密码`，底层服务仍按普通 IPv4 SOCKS5 用户名/密码认证提供 TCP `CONNECT`。

## 本地验证

- `go test -mod=readonly ./...`、`go test -race ./...`、`go vet ./...` 通过。
- 八组既有 Shell 回归通过；新增链接测试覆盖落盘权限、无网络缓存读取、凭据更新、手动刷新、刷新失败保留旧链接和多配置共用一次查询。
- 特殊字符凭据与中文备注完成 URI 解码回验；用户名含冒号时返回手动填写提示，保持 SOCKS 本身的凭据规则。
- `scripts/install.sh` 通过 `bash -n`；发布包按双架构成员清单、源码摘要、依赖锁定、二进制元数据、安装器版本和 SHA-256 门禁验证。
- ShellCheck 保留五项历史告警，本次没有新增告警。
- 实例导入链接格式使用 233boy/Xray 客户端兼容的 `socks://Base64@IPv4:port#name-IP` 形式；私有或非 IPv4 地址拒绝生成。

## 实机验收缺口

本版本未进行 Linux VPS 的实际写入验收或客户端 UI 导入验收；systemd、真实 nftables、双架构 Linux 流量、客户端导入连接与公网地址变化后的手动刷新仍需在授权测试环境核对。
