# Socks-VPS v1.0.2 handoff

日期：2026-07-26
来源：tag `v1.0.2`、commit `806e2fb` 和 GitHub Release；历史回填。

## 改动

macOS 使用 bsdtar 构建时显式关闭扩展属性、ACL、file flags 和 AppleDouble
元数据，并统一归档成员的 root 所有权。Linux 解包不再出现来自构建主机的
扩展头或属性警告。

## 影响

- 发布包只包含 allowlist 中的版本化项目文件。
- 包内文件与源码、manifest 和锁定重建结果继续逐字节核对。
- 不改变 SOCKS 协议、防火墙、配置或生命周期行为。

## 后续发现

Ubuntu 22.04 的 `nft --json list table` 不返回 table 注释，导致 v1.0.2
不能稳定证明自有表所有权；原生 nftables 服务的 reload/restart 生命周期
也需要协调。这些问题在 v1.0.3 修复。当前状态只以根目录 `HANDOFF.md`
为准。
