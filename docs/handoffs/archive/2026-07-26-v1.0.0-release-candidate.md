# Socks-VPS v1.0.0 发布候选 handoff

日期：2026-07-26
状态：历史回填；本地实现和包校验完成，真实 VPS 与公开发布当时仍未完成。

## 已实现

- 独立 Go SOCKS5 服务，IPv4-only、TCP `CONNECT`、RFC 1929 强制认证。
- A 记录解析、`tcp4` 出站和公网 IPv4 目标限制。
- `table ip socks_vps`、CN IPv4 interval set 和 systemd 防火墙依赖链。
- 自动/手动端口选择、配置权限、专用 nologin 账户。
- 安装、重复运行、更新、完整备份、可恢复卸载和部分移动恢复。
- IPdeny 原始 CN zone、版权、MD5 与来源元数据随发布包交付。

## 当时本地证据

- Go 单元测试、race、vet、gofmt 和模块锁检查通过。
- Bash 语法与账户、生命周期、监听归属、恢复测试通过。
- amd64 与 arm64 归档通过成员 allowlist、逐文件 manifest、IPdeny 字节、
  源码清单、ELF 架构和锁定源码重建校验。
- 构建使用 `CGO_ENABLED=0` 和锁定的
  `github.com/go-gost/gosocks5 v0.5.0`。

## 当时阻断项

- 工作目录尚未初始化 Git，没有远端、commit 或公开 Release。
- 公开安装脚本仍含发布主机占位符。
- 项目自身许可证尚未确定。
- macOS 本地检查不能证明 Linux systemd、nftables、CN 来源阻断或真实
  SOCKS 出口。
- DNF/YUM、arm64 真机、真实 CN/GFW、firewalld/UFW 和 WARP 共存未验收。

## 后续结果

公开仓库和 v1.0.0 随后建立；v1.0.1、v1.0.2 处理构建可重现性与归档宿主
元数据，v1.0.3 完成 Ubuntu 真机修复和验收。当前状态只以根目录
`HANDOFF.md` 为准。
