# Socks-VPS v1.0.1 handoff

日期：2026-07-26
来源：tag `v1.0.1`、commit `fe20864` 和 GitHub Release；历史回填。

## 改动

发布构建和校验重建统一增加 `-buildvcs=false`，不再把当前 Git checkout
状态写入 Go 二进制。源码 manifest 继续作为 build ID，归档内二进制仍需
与锁定依赖和当前源码的重建结果逐字节一致。

## 影响

- 从“项目尚未初始化 Git”的目录构建和从正式仓库构建得到相同发布输入。
- 不改变 SOCKS 协议、认证、目标限制、防火墙、配置或生命周期行为。
- 外层 GitHub Release 资产结构保持不变。

## 剩余问题

macOS 归档宿主元数据、真实 VPS 验收和项目自身许可证仍未闭环，分别在后续
版本处理。当前状态只以根目录 `HANDOFF.md` 为准。
