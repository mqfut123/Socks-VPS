# Socks-VPS v1.0.0 handoff

日期：2026-07-26
来源：tag `v1.0.0`、commit `f407e9c` 和 GitHub Release；历史回填。

## 交付

首次公开交付完整 Socks-VPS v1：

- Linux `amd64`、`arm64` 静态 Go 二进制。
- 一条版本化 Bash 安装入口和归档 SHA-256。
- IPv4-only SOCKS5、TCP `CONNECT`、RFC 1929 认证。
- 公网 IPv4 目标限制和 A 记录解析。
- 内置 IPdeny CN IPv4 aggregated 数据。
- 独立 `table ip socks_vps` 与两个 systemd units。
- 更新、可恢复卸载与恢复入口。

## 发布契约

GitHub Release 包含 bootstrap、两个架构归档及各自校验值。VPS 只获取项目
发布包，不另行下载 IPdeny、规则、unit 或运行依赖。

## 当时已知限制

- 构建结果仍可能受 Git 仓库状态影响。
- macOS 生成的归档仍可能携带宿主扩展元数据。
- 真实 Ubuntu systemd/nftables 和资源占用验收尚未形成完整证据。
- 项目自身许可证尚未确定。

上述问题分别在 v1.0.1、v1.0.2、v1.0.3 和 v1.0.4 处理。当前状态只以
根目录 `HANDOFF.md` 为准。
